Billard game tracking using C, Matlab and Labview 
# Billard Project

## Overview

This project implements a billiard analysis pipeline in three parts:

1. **C program (`Pix2Pos`)**  
   Reads a binary pixmap file, detects the ball positions, and writes the results to `Pos.txt`.

2. **LabVIEW VI (`Billard2025.vi`)**  
   Acts as the main controller. It reads the video frames, generates `Pixmap.bin`, calls the C program, stores the ball positions, and generates the MATLAB script.

3. **MATLAB script (`AnalyseTx.m`)**  
   Analyzes the billiard sequence using the positions produced by the previous steps, then generates the final report and PDF figure.

The LabVIEW part uses the **System Exec VI** to launch command-line programs and pass the full command as a string in the `command line` input [web:3][web:6].

## Project Structure

Typical project files:

- `Pix2Pos` / `Pix2Pos.exe`: C executable.
- `Billard2025.vi`: main LabVIEW VI.
- `AnalyseTx.m`: MATLAB analysis script generated by LabVIEW.
- `Pixmap.bin`: binary image data produced by LabVIEW.
- `Pos.txt`: ball positions produced by the C program.
- `SummaryTx.txt`: text summary produced after MATLAB analysis.
- `ScoreSheetTx.pdf`: final PDF report produced by MATLAB.

## Workflow

### 1. Image processing in LabVIEW
LabVIEW loads the video frames, extracts the pixels, and writes the binary image data into `Pixmap.bin`.

### 2. C execution
LabVIEW builds a command line containing the executable name and all required parameters, then runs it with the System Exec VI [web:3][web:6].  
The C program reads `Pixmap.bin`, processes the image, and writes the ball coordinates into `Pos.txt`.

### 3. MATLAB analysis
LabVIEW generates the MATLAB script `AnalyseTx.m` using the chosen parameters and launches MATLAB.  
MATLAB reads the ball positions, detects the game events, and creates the final report.

## C Program Role

The C executable `Pix2Pos`:

- reads `Pixmap.bin`;
- validates command-line parameters;
- decodes pixels in `0x00RRGGBB` format;
- searches for the best `BallDiameter x BallDiameter` regions for each ball color;
- writes the positions and scores to `Pos.txt`;
- reports errors through `stderr` when needed.

The program uses command-line arguments passed by LabVIEW, which is the standard way to provide inputs to a C program from another application [web:11][web:12].

## LabVIEW Role

`Billard2025.vi` is the main orchestrator:

- selects the image sequence;
- reads each PNG frame;
- finds the billiard borders;
- writes `Pixmap.bin`;
- calls the C program `Pix2Pos`;
- retrieves and stores the computed coordinates;
- generates the MATLAB analysis script;
- launches MATLAB and handles errors.

In LabVIEW, external programs are launched with the System Exec VI, and the entire command including parameters is passed through the `command line` terminal [web:3][web:6].

## MATLAB Role

The MATLAB script `AnalyseTx.m`:

- loads the positions produced by `Pix2Pos`;
- handles missing values and outliers;
- detects ball motion, wall rebounds, and ball collisions;
- determines whether the player scored;
- generates the final figure and saves it as a PDF.

## Error Handling

The project includes error handling at several levels:

- **C program errors**: invalid arguments, missing file, unreadable file, insufficient pixels, or invalid output file.
- **LabVIEW errors**: missing executable, invalid PNG frame, file creation issues, or execution failure.
- **MATLAB errors**: invalid script generation, missing inputs, or analysis failure.

The C program should report critical issues to `stderr`, while LabVIEW should capture and manage execution errors from the external process [web:11][web:13].
